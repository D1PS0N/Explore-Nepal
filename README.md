# Explore Nepal

Explore Nepal is a tourism website developed using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

## Features

- User Registration & Login
- View Tourist Destinations
- Destination Details
- Search Destinations
- Responsive Design
- Admin Destination Management (In Progress)

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## How to Run

1. Import `database/explore_nepal.sql` into MySQL.
2. Create a `.env` file in the `backend` folder.
3. Run:

```bash
npm install
node server.js
```

4. Open `frontend/index.html` using Live Server.
